# SIPERPUS AI

Sistem Perpustakaan Digital (PHP Native 8.2 + MySQL)

Instalasi singkat:
1. Import database/perpus_schema.sql
2. Edit config/database.php
3. Letakkan folder di htdocs (C:\xampp\htdocs\perpus_ai) atau set virtual host
4. Buka http://localhost/perpus_ai/public

Catatan: Anda harus menempatkan UI Google Stitch di public/ui/ (disediakan oleh Anda). Jika belum ada, buka http://localhost/perpus_ai/public dan unggah UI.
